# Arine

> Arine is a San Francisco-based healthcare technology company operating an AI-driven medication intelligence and comprehensive medication management platform for health plans, government payors and risk-bearing provider organizations. It ingests pharmacy and medical claims, clinical, cost, quality, behavioral and social-determinants-of-health data, then applies machine learning and clinical decision logic to surface medication-related gaps in care and generate targeted interventions, member education materials and prescriber communications.

Generated by the API Evangelist enrichment pipeline on 2026-08-02 from apis.yml and the artifacts in this repository. Arine does not publish an llms.txt of its own.

## API status

Arine ships **no public developer program and no publicly available machine-readable API contract**. Verified 2026-08-02:

- `https://api.arine.io` is an AWS API Gateway that answers every path — including `/openapi.json`, `/swagger.json`, `/graphql` and `/.well-known/*` — with HTTP 403 `ForbiddenException` to anonymous callers.
- `https://docs.arine.io` is a Document360 knowledge base with `projectProtectionLevel: 1`; every path 302-redirects to an OIDC login.
- No OpenAPI, Swagger, GraphQL SDL, AsyncAPI, MCP server, A2A agent card, SDK, CLI, Postman collection or public changelog was found on any Arine host or in any public package registry.

Integration with Arine is a commercial, contracted arrangement. Start at the contact and demo links below.
